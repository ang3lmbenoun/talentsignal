# Screenshots

The main [README](../../README.md) expects five screenshots in this folder. They are not captured
yet. Add them with exactly these file names, then replace the placeholder lines in the README's
"What it does" section with image links.

| File | What to capture |
|---|---|
| `login.png` | The login screen with the animated backdrop |
| `overview.png` | Overview with the KPI tiles and one "How is this counted?" note open |
| `opportunities-card.png` | One opportunity card: the verdict sentence, the contribution bar and the evidence chip |
| `signals.png` | The Signals screen with the source-health panel |
| `guided-tour.png` | The guided tour, mid-step, with the spotlight on a real element |

Capture tips:

- Use the seeded demo data only (`npm run seed:demo`), never real client data.
- Sign in with a throwaway account. Do not include a real email address in the frame.
- Crop out the browser bar, tabs and bookmarks.
